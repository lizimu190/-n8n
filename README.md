📰 AI 驱动的科技资讯 RSS 分析与邮件分发工作流 （n8n）
基于 n8n 构建的自动化工作流。 该工作流会定时抓取头部科技媒体（36氪、少数派）的 RSS 订阅，通过大语言模型（LLM）化身“资深科技行业分析师”对新闻进行核心价值总结与行业影响力打分，并根据得分高低将资讯分发至指定的邮箱。

✨ 核心功能
⏰ 定时触发：默认每 20 小时自动运行一次，无需人工干预。

📡 多源 RSS 聚合：原生支持抓取 36氪 和 少数派 的最新文章，提取内容摘要。

🧠 AI 深度分析：

内置精心调优的 Prompt，让 AI 扮演拥有 10 年经验的资深科技分析师。

自动剔除公关废话，强制输出精准的 3 句话总结。

对新闻的行业“影响力与重要性”进行 1-10 分的量化评估。

⚙️ 稳健的数据处理：内置 JavaScript 脚本，自动清理和解析大模型输出的 JSON 数据，并包含异常容错机制（防止 AI 格式幻觉导致工作流中断）。

🔀 智能路由与邮件提醒：

高优资讯（得分 > 6 分）：发送主题为“数据分数大于6”的重点提醒邮件。

常规资讯（得分 ≤ 6 分）：发送主题为“数据抓取小于6”的汇总邮件。

🗺️ 工作流架构
Schedule Trigger： 触发器，控制抓取频率。

RSS Read： 分别读取 36氪 和 少数派 的 Feed 源。

Edit Fields & Merge： 统一提取文章摘要（）并合并数据流。contentSnippet

AI Agent （Qwen-turbo）： 调用兼容 OpenAI 格式的大语言模型 API 进行结构化信息提炼。

Code （JS）： 解析 AI 输出的 JSON，格式化 、 和 字段。summaryscorereason

If： 根据打分 （） 进行条件分支。score > 6

Email Send： 通过 SMTP 协议发送邮件。

🚀 部署与使用指南
1. 环境准备
已安装并运行的 n8n 实例（本地化部署或 Cloud 版本均可）。

一个支持 OpenAI API 格式的大模型 API Key（工作流默认配置为阿里云的 模型）。qwen-turbo

用于发送邮件的 SMTP 账号及授权码（如 QQ 邮箱、网易邮箱或 Gmail 等）。

2. 导入工作流
下载本项目中的 文件。rss抓取信息发送邮件.json

打开你的 n8n 面板，进入工作流列表页面。

点击右上角的 Import from File，选择该 JSON 文件即可导入。

3. 配置凭据 （Credentials）
导入后，你需要重新配置节点中的敏感凭证：

OpenAI Chat Model 节点： 创建或选择你的 凭证（填入你的 API Key 和 Base URL）。OpenAi API

Send an Email 节点： 创建或选择你的 凭证（填入 SMTP 服务器地址、端口、发件邮箱及密码/授权码）。SMTP account

4. 个性化修改 （必看）
修改收发件邮箱：默认节点中硬编码了邮箱 ，请务必在两个 Send an Email 节点中将其修改为你自己的邮箱地址。2516181455@qq.com

修改 RSS 源：你可以直接在 RSS Read 节点中替换 URL（例如加入极客公园、虎嗅等的 Feed 链接）。

调整打分阈值：在 If 节点中，你可以将触发高优邮件的分数线（当前为 ）调整为你认为合理的数值。6
